# Cadence

Carnet de suivi pour traitements GLP-1 (Mounjaro, Wegovy, Ozempic, Saxenda) et peptides : injections, rotation des zones, niveau estimé, poids, ressentis, stock, rappel calendrier, export JSON/CSV.

Site statique sans build ni serveur : les données restent dans le navigateur (localStorage). Pour publier, activer GitHub Pages sur la branche `main`, dossier racine.

Cadence est un outil de suivi personnel et ne fournit aucun conseil médical.
